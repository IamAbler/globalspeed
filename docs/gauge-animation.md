# 仪表动画

## 参考研究

2026-10-05 使用浏览器打开 [Speedtest 官网](https://www.speedtest.net/)，读取页面实际加载的 [前端 JavaScript](https://r.cdnst.net/assets/index-BN2jg79U.js)。该资源文件名可能随发布变化。原始脚本和研究截图只保存在本地临时目录，不加入本项目。

读取到的机制：

| 项目 | 官网实现 |
| --- | --- |
| 绘制与驱动 | SVG，React，Motion 的逐帧动画 |
| 表盘 | 270°，角度从 -135° 到 135° |
| 刻度 | 0、5、10、50、100、250、500、750、1000 |
| 速度映射 | 刻度等角度排列，每段内部按速度线性插值，超量程时停在末端 |
| 实时指针 | 200 ms，ease-out：cubic-bezier(0,0,0.58,1) |
| 阶段回针 | 500 ms，ease-in-out：cubic-bezier(0.42,0,0.58,1) |
| 入场 | 圆盘展开成环约 200 ms，环打开为弧约 150 ms |
| 刻度 | 逐个间隔 80 ms，淡入约 80 ms |
| 结束 | 100 ms 淡出、100 ms 暂停、220 ms 弧变环、220 ms 环变盘、180 ms 淡出 |
| 配色 | 上下行及单/多连接有独立渐变纹理；指针为半透明宽指针 |

数值观察有一个差别：官网仪表数字直接格式化当前采样值，指针单独缓动。本项目继续让数字也做缓动，以满足实时读数平滑的要求。

## GlobalSpeed 实现

本项目自行编写动画，不引入官网测量引擎、广告、原始脚本或渐变图片。

- `frontend/src/gaugeMotion.ts`：分段角度映射与贝塞尔缓动。
- `frontend/src/useAnimatedSpeed.ts`：200 ms 指针/数字重定向，阶段切换先回到零点，随后跟随最新采样。
- `frontend/src/Speedometer.tsx`：270° SVG 表盘、独立渐变、宽指针、圆盘/环/弧变形。
- `frontend/src/main.tsx`：在测速结束后保留约 820 ms 的回收展示，再显示最终结果。

刻度位置和跟随/回针时间按参考行为实现；颜色使用本项目生成的 SVG 渐变。量程固定至 1000 Mbps，末端标为 1000+；更高速度仍按实际数值显示，指针停在量程末端。布局保留 GlobalSpeed 的紧凑窗口适配。

动画只影响展示。Go 核心的采样、最终结果、流量预算与历史数据均不因动画而改变。启用系统“减少动态效果”时直接更新数值，跳过变形和回针等待。

## 验证

浏览器检查覆盖分段量程、贝塞尔中点、实时中间值、最终数值不变、阶段回针、入场与退出状态，以及 800×520、960×640、1280×720 客户区的内容完整性。使用模拟 Go 事件，未运行官网速度测试。
